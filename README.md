## Resumen

En estas prácticas aprendí a armar pequeñas partes de un programa y a darles información para que trabajen, además de entender qué pasa con los datos cuando cambian dentro de ellas, y también aprendí en qué lugar del programa vive cada dato, así como a usar herramientas que el lenguaje ya trae listas para hacer cálculos, escoger números al azar y revisar letras y palabras.
